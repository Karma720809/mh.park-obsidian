## 1️⃣ 모듈 (Module)

**한 줄 핵심**: 단백질은 태어나서, 접히고, 검사받고, 재활용되거나 죽는다

```
DNA
 ↓ Pol II (전사)
mRNA (m7G 캡 + poly-A tail)
 ↓ 80S 리보솜 (60S + 40S) (번역)
단백질
 ↓ ER 진입 → N-Asn 글리코실화 → Calnexin (폴딩 보조)
 ├─ 정상 폴딩 → Golgi (Cis→Trans→TGN) → 분비 / 막 삽입
 └─ 미스폴딩 → ER stress → UPR
                              ├─ ERAD (Ubiquitin-Proteasome)
                              └─ Autophagy
```

---

## 2️⃣ 대칭 (Symmetry)

**ER stress 3총사 — 같은 목적, 세 방향**

| 센서 | 신호 경로 | 효과 |
|------|-----------|------|
| PERK → eIF-2α 인산화 | ATF4 → CHOP | 번역 정지 (긴급 멈춤) |
| IRE1 → XBP1 스플라이싱 | XBP1s | 샤페론 증가 (구조대) |
| ATF6 → 절단 → ATF6c | ERAD 강화 | 쓰레기 청소 |

> 대칭: 만들기 줄이기 ↔ 처리 늘리기 ↔ 치우기 — 세 방향이 하나의 목적

**Ubiquitin 76aa ↔ SUMO ~100aa**: 둘 다 단백질 수식자(tag)이지만
- Ubiquitin → 분해 신호
- SUMO → 기능 조절 신호

## 3️⃣ 순서 (Sequence)

```
E1 (활성화 효소, 2종) — ATP 소비
 ↓
E2 (접합 효소, 40종)
 ↓
E3 (리가아제, 700종 — APC/C 포함)
 ↓ Ub 체인 부착
26S 프로테아솜 (19S CAP + 20S core + 19S basal)
 ↓ 분해
아미노산 → 재활용
```

*분포: 핵 70% / 세포질 30%*

## 4️⃣ 연결 (Connections)

```
PI(4,5)P₂ → IP₃ + DAG → Ca²⁺ / PKC
PI(3,4,5)P₃ → Akt → mTOR ↑
              ↑
          PI3K (Insulin/EGF/IGF-1)
              ↑
          PTEN ↓ (종양억제유전자)
```

- [[암생물학]]: PTEN 변이 = 세포 무한증식
- 소기관 지질 분업: ER→인지질합성 / Peroxisome→Plasmalogen / Golgi→Sphingomyelin
- PS flip: Caspase → 'eat me' 신호 → 식세포 제거
